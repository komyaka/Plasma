## 3. Предложения по модернизации

### Приоритет: Высокий

1. **Параметризованные SQL-запросы** — заменить все конкатенации строк на `SqlParameter`. Это критически важно для безопасности. Текущий код уязвим к SQL-инъекциям.

2. **Логирование ошибок** — заменить пустые `catch {}` на запись в лог (NLog или Serilog). Сейчас ошибки БД проглатываются молча.

3. **Кеширование данных** — `PartsClass` загружает все данные при каждом запросе. Внедрить кеширование (`MemoryCache`) с инвалидацией при изменениях.

4. **Connection pooling** — использовать `using` для `SqlConnection` вместо ручного `Open/Close`. Это гарантирует возврат соединений в пул.

### Приоритет: Средний

5. **Миграция на Entity Framework** — заменить ручные SQL-запросы на ORM. Упростит поддержку и защитит от SQL-инъекций.

6. **Вынести строку подключения** из кода в `Web.config` (секция `connectionStrings`). Пароль БД не должен быть в исходном коде.

7. **Обновить Bootstrap** с версии 3 до 5 — улучшит адаптивность, доступность и поддержку современных браузеров.

8. **REST API** — привести API-контроллеры к REST-стандарту с правильными HTTP-методами (GET, POST, PUT, DELETE) и кодами ответов.

9. **Единый механизм загрузки файлов** — объединить дублирующийся код в `APIController` и `adrController` в один сервис.

### Приоритет: Низкий

10. **Перенос на .NET 6/8** — ASP.NET MVC 5 (.NET Framework) больше не развивается. Миграция на ASP.NET Core даст кроссплатформенность и производительность.

11. **Клиентская пагинация/виртуализация** — при большом количестве программ/деталей страницы тяжёлые. Внедрить серверную пагинацию.

12. **Юнит-тесты** — покрыть тестами парсинг CNC-файлов и расчёт скоростей (наиболее критичная бизнес-логика).

13. **Поддержка `.xlsx`** — заменить Koogra на EPPlus/ClosedXML для чтения современных Excel-файлов.

14. **WebSocket для обновлений** — заменить периодический polling (каждые 18 сек) на SignalR для мгновенных уведомлений об изменениях данных.

15. **Экспорт отчётов** — добавить экспорт таблиц в Excel/PDF для бухгалтерии и руководства.
