# PLASMA — Система управления плазменной резкой

## Описание

**PLASMA** — веб-приложение для управления производственным процессом плазменной резки металла. Система обеспечивает полный цикл учёта: от поступления металлических листов на склад до отгрузки готовых деталей заказчику.

### Основные функции

- **Управление CNC-программами** — загрузка, просмотр, удаление программ раскроя; визуализация раскладки деталей на листе (Canvas/SVG); отметка выполненных программ.
- **Учёт листов металла** — приход листов на склад; привязка листов к программам раскроя; просмотр остатков по толщинам, материалам, размерам.
- **Учёт деталей** — автоматический парсинг списка деталей из CNC-файлов; отслеживание количества вырезанных/требуемых деталей; фильтрация и сортировка по параметрам.
- **Управление заказами** — просмотр текущих заказов; автоматическая проверка готовности заказа (сопоставление с Excel-расчётами); калькуляция стоимости из XLS-файлов.
- **Отгрузки** — полная и частичная отгрузка заказов; история отгрузок.
- **Система привилегий** — ролевое управление доступом через битовую маску (32768 уровней доступа).

### Принцип работы

1. Оператор загружает CNC-файлы (формат `.CNC` — G-код для плазменного станка).
2. Система автоматически парсит файл: извлекает список деталей с размерами, количеством, толщиной; определяет материал по имени файла; рассчитывает время резки.
3. Кладовщик вносит приход листов металла на склад.
4. Мастер привязывает листы к программам раскроя (страница «Отметить порезанные»).
5. После выполнения программы оператор отмечает её как выполненную — система автоматически обновляет количество вырезанных деталей.
6. Система автоматически проверяет готовность заказов, сопоставляя данные из Excel-расчётов с фактически вырезанными деталями.
7. Готовые заказы отгружаются (полностью или частично).

## Установка и настройка

### 1. Подготовка базы данных

Создайте базу данных `PLASMA` на SQL Server. Необходимые таблицы:

- `CNCFILES` — хранение CNC-программ
- `PARTS` — хранение деталей
- `SHEETS` — учёт листов металла
- `MATERIALS` — справочник материалов
- `USERS` — пользователи системы
- `Chapters` — разделы сайта и права доступа
- `ORDERS` — представление/таблица текущих заказов
- `SHIPMENT` — отгрузки

### 2. Настройка конфигурации

Отредактируйте файл `Models/AppConfig.cs` — конфигурационный файл приложения. В нём задаются:

- Строка подключения к базе данных
- Пути к файлам CNC-программ
- Путь к сетевой папке с расчётами
- URL-адреса API и контроллеров

Подробные комментарии по каждому параметру — внутри файла.

### 3. Настройка IIS

1. Создайте пул приложений с поддержкой .NET Framework 4.7.2.
2. Включите Windows-аутентификацию для сайта.
3. Отключите анонимную аутентификацию.
4. Убедитесь, что пул приложений работает от имени доменной учётной записи с доступом к SQL Server и сетевым папкам.

### 4. Развёртывание

```
1. Откройте решение Plazma.sln в Visual Studio.
2. Выполните сборку (Build → Build Solution).
3. Опубликуйте проект (Build → Publish).
4. Скопируйте опубликованные файлы в директорию сайта IIS.
```

### 5. Настройка папок

Убедитесь, что существуют и доступны для записи следующие директории (пути настраиваются в `AppConfig.cs`):

- Папка CNC-файлов (по умолчанию `D:\PlazmaProgs`)
- Папка для новых загружаемых файлов (по умолчанию `D:\PlazmaProgs\NewFiles`)
- Папка архива (по умолчанию `D:\PlazmaProgs\arhive`)
- Сетевая папка с расчётами (по умолчанию `\\korolev\_Плазменная резка`)

## Система привилегий

Доступ управляется через битовую маску. Каждый бит отвечает за отдельный раздел:

| Код   | Раздел                              |
|-------|-------------------------------------|
| 2     | Управление программами              |
| 4     | Просмотр/редактирование деталей     |
| 8     | Просмотр листов                     |
| 16    | Добавление листов                   |
| 32    | Отметка порезанных листов           |
| 64    | Просмотр заказов и калькуляций      |
| 128   | Управление отгрузками               |
| 256   | Просмотр калькуляций                |
| 32768 | Администрирование (все функции)     |

Привилегии хранятся в таблице `USERS` (поле `FUNCT`) и комбинируются побитовым ИЛИ.

## Известные ограничения

- Приложение работает только в среде Windows с IIS и Active Directory.
- Парсинг CNC-файлов поддерживает только формат ESSI/ISO (G-код для плазменных станков).
- Чтение Excel-расчётов поддерживает только формат `.xls` (не `.xlsx`).
- Сортировка и фильтрация на стороне сервера — при большом объёме данных возможны задержки.
